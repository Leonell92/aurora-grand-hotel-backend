# Dependencies

## Frontend Key Dependencies (`package.json`)
- `react`, `react-dom` (v18.3): Core UI library.
- `vite` (v7.3): Fast frontend build tool.
- `@tanstack/react-query` (v5.83): Advanced data fetching, caching, and state synchronization.
- `axios` (v1.13): Promise-based HTTP client for API requests.
- `react-router-dom` (v6.30): Declarative routing for React.
- `tailwindcss` (v3.4): CSS framework.
- `@radix-ui/react-*`: Unstyled accessible UI primitives used by Shadcn.
- `lucide-react`: SVG icon library.
- `react-hook-form` & `zod`: Form handling and schema-based validation.
- `embla-carousel-react`: Lightweight carousel used for image sliders (rooms/amenities).
- `date-fns` & `react-day-picker`: Date manipulation and calendar UI components.
- `sonner`: Toast notification library.

## Backend Key Dependencies (`requirements.txt`)
- `Django` (v6.0): Core web framework.
- `djangorestframework` (v3.15): Powerful toolkit for building Web APIs.
- `django-cors-headers` (v4.3): Middleware to handle Cross-Origin Resource Sharing.
- `psycopg`: PostgreSQL database adapter for Python.
- `dj-database-url`: Utility to help load database config from the `DATABASE_URL` environment variable.
- `python-decouple`: Strict separation of settings from code.
- `whitenoise`: Simplified static file serving for Python web apps.
- `gunicorn`: Python WSGI HTTP Server for UNIX (Production server).
